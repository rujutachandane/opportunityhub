OpportunityHub is a clean, modern, student-friendly web application designed to help college students discover internships, hackathons, 
competitions, scholarships, courses, certifications, and workshops in one centralized dashboard.
Main GoalOpportunityHub eliminates the time students waste hunting for opportunities across scattered websites, LinkedIn posts, and WhatsApp groups by consolidating relevant, verified opportunities into a single portal.V

Visual ThemePrimary Color: Emerald Green for main buttons, navigation, and primary badges.
Secondary Accent: Radiant Amber Yellow for match percentages, featured badges, and notifications.
Background & Text: Light mint tint with dark charcoal typography
.Design Style: Modern cards, 16px rounded corners, box-shadows, and clean responsive layouts.
Key FeaturesLanding Page: Features a hero section, instant search, a 7-category explorer with live counters, and curated top opportunities.
Explore & Multi-Filter System: Allows instant search by title, skill, or organization.
Filters by category, mode (online, offline, hybrid), skills, and deadline urgency. Sorting options include deadline and match percentage.


Recommendation Engine: Compares student profile attributes against requirements to generate a Match Percentage Score (0% to 98%) and highlight matched skills.S
student Dashboard: Welcomes students by name, provides real-time statistics (total found, saved bookmarks, high matches, urgent deadlines), and displays a chronologically sorted deadline tracker.
Profile Management: Persists student data (name, college, year, skills, interests) locally in the browser to instantly recalculate recommendation scores.Saved Opportunities: Allows one-click bookmarking to manage saved items and track upcoming application deadlines.
